## What is Aayushi Code?

Aayushi Code is a fast, native code editor built in Rust with a
GPU-accelerated renderer — a combination that makes even very large projects
feel instant. It uses familiar editing conventions so you can switch without
relearning your workflow, and it has no account, no telemetry, and nothing to
sign in to.
