The first stable release of Aayushi Code is here.

{/* truncate */}

## What's in this release

- A polished, GPU-accelerated editor built on the Rust stack.
- Built-in language support with tree-sitter grammars and LSP integration.
- A familiar UI with the project panel, terminal, tasks, and debugging.
- First-class theme support with light and dark color schemes.

## Supported platforms

Stable builds are published for:

- **macOS** — Apple Silicon and Intel
- **Linux** — x86_64 and aarch64 (tarball)
- **Arch Linux** — x86_64 and aarch64 (`.pkg.tar.zst`)
- **Windows** — x86_64 (installer)
- **Debian / Ubuntu** — `.deb` package

Grab your build on the [download page](/download), and check the
[release notes](https://github.com/aayushpokhrel49/aayushii-code/releases)
for the full changelog.
