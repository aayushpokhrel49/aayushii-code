# Interface

Aayushi Code's layout is a single, dockable workspace.

## The workspace

- **Left dock** hosts the project panel (file explorer).
- **Center** is the editor with tabs for open buffers.
- **Bottom dock** hosts the terminal, tasks, and diagnostics panels.
- **Right dock** hosts the outline, project symbols, and other auxiliary
  views.

Toggle docks from the view menu or with the default keybindings (see
[Keyboard shortcuts](shortcuts.md)).

## Project panel

Shows the file tree of the current project. Right-click a file for actions
such as opening, revealing in the file finder, copying the path, renaming, or
deleting. New files and folders can be created from the panel's toolbar.

## Editor

- Tabs across the top let you switch between open buffers.
- Multiple tabs can be split into panes — use the split actions from the
  tab's right-click menu.
- The status bar at the bottom shows language, line/column, encoding, and
  diagnostic counts.

## Previewing files

Use the file finder (<kbd>Ctrl/Cmd</kbd>-<kbd>P</kbd>) to jump to any file
quickly, or the fuzzy file filter for symbol-aware navigation.

## Settings UI

Run **Settings** from the command palette to edit your user settings with
autocomplete for every option. Changes apply immediately.

### Common settings categories

**Editor Settings:**
- Font family and size
- Tab size and indentation
- Line height and spacing
- Scroll behavior
- Whitespace display

**Theme Settings:**
- Light/dark mode
- Color scheme selection
- Syntax theme
- UI theme customization

**Language Settings:**
- Language server configuration
- Formatter settings
- LSP options
- Language-specific preferences

**Keybindings:**
- Custom keyboard shortcuts
- Keybinding conflicts resolution
- Mode-specific bindings
