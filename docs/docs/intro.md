# Welcome to Aayushi Code

Aayushi Code is a fast, native code editor built in Rust with a
GPU-accelerated renderer. It combines the speed of a native application with
the familiarity of a modern IDE.

## Highlights

- **Native and fast.** No Electron, no webviews. Written in Rust, rendered on
  the GPU.
- **Familiar.** The UI and default keybindings feel like the editors you
  already know.
- **Private.** No account required, no telemetry, nothing phoning home.
- **Open source.** Released under the GPL-3.0 and Apache-2.0 licenses.

## Quick start

```sh
# macOS
brew install --cask aayushicode   # or download the DMG

# Linux
tar -xzf aayushicode-linux-$(uname -m).tar.gz -C ~/.local

# Arch Linux
sudo pacman -U ./aayushicode-*.pkg.tar.zst

# Windows
# Run the downloaded AayushiCode-x86_64.exe installer
```

Then launch the editor and open a folder — that's it.
